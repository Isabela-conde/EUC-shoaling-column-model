# EUC shoaling: 1-D column experiments

Does surface warming shoal the Equatorial Undercurrent by moving the zonal
pressure gradient (Peng et al. 2022) or through the stratification and the
mixing in the shear layer above the core (Saenko et al. 2011)? A single-column
KPP model at 0°, 140°W, forced with ACCESS-OM2 profiles, imposes each change
separately. Wind stress is held at its control value in every run (fixed-wind
experiments, as in Peng et al.), so the column isolates the ocean's response
to warming.

Companion to the ACCESS-OM2 tropical-warming experiments (control `era5`,
warming `tas_053`).

## Layout

| path | what |

| `scripts/euc_scaling.py` | Pedlosky inertial-scaling test on the ACCESS runs (fractional trends, exponent fit) |

## The column model

### Equations

Zonal momentum, temperature and salinity in one vertical column, no rotation
(f = 0 at the equator), no meridional velocity:

    ∂u/∂t = PGF(z) − w(z) ∂u/∂z − u/τ_d + ∂/∂z( ν ∂u/∂z )
    ∂T/∂t = (T*(z) − T)/τ_T       + ∂/∂z( κ ∂T/∂z ) + KPP non-local flux
    ∂S/∂t = (S*(z) − S)/τ_T       + ∂/∂z( κ ∂S/∂z )

| term | what it is | where it comes from |
|---|---|---|
| PGF(z) | zonal pressure-gradient force −(1/ρ₀)∂p/∂x, a fixed profile | ACCESS, fitted over 150°W–130°W (see Inputs) |
| −w ∂u/∂z | vertical advection by the mean upwelling | ACCESS `wt`, fixed profile |
| −u/τ_d | Rayleigh drag, τ_d = 60 d | stands in for everything 3-D: meridional divergence and horizontal advection. Its size relative to the PGF at the core is printed (Ray/PGF ≈ 0.2–0.3). Sensitivity to τ_d = 30/60/90/180 d is run on the control each time |
| ∂z(ν ∂z u) | vertical mixing of momentum | KPP + LMD94 interior shear mixing (below) |
| (T* − T)/τ_T | restoring of T and S toward the ACCESS profile, τ_T = 20 d | ACCESS profiles; this is how the stratification is imposed |

Boundary conditions: top momentum flux τ_x/ρ₀ with τ_x the **control** stress
(−0.045 N m⁻²) in all runs; top heat flux λ_fb (SST − SST*)/(ρ₀ c_p) with
λ_fb = 40 W m⁻² K⁻¹ and SST* the ACCESS SST of the run whose stratification is
imposed; zero flux at the bottom (400 m). No restoring on u anywhere.

Linear equation of state: α = 2.0e-4 K⁻¹, β = 8.0e-4 psu⁻¹, ρ₀ = 1026 kg m⁻³,
g = 9.81 m s⁻², c_p = 3991 J kg⁻¹ K⁻¹.

Initial condition: the ACCESS u, T, S profiles of the run whose stratification is
imposed. The jet is then regenerated by the PGF against drag and mixing, so the
initial u is forgotten (spin-up figure: centroid flat well before day 540).

### Mixing

OceanTurb.jl's KPP (Large et al. 1994 boundary layer with non-local flux,
`KPP.Parameters` defaults except the backgrounds) plus the LMD94 interior
shear-instability term that OceanTurb omits and MOM5/ACCESS-OM2 use:

    ν_shear(Ri) = ν₀ (1 − (Ri/Ri₀)²)³   for 0 ≤ Ri < Ri₀,   ν₀ for Ri < 0,   0 for Ri ≥ Ri₀
    ν₀ = κ₀ = 5e-3 m² s⁻¹,  Ri₀ = 0.7

added to `KPP.KU` and `KPP.KT` by method overload. Backgrounds (MOM5): ν = 1e-4,
κ_T = κ_S = 1e-5 m² s⁻¹. With this, the control column has a KPP boundary layer
of ~48 m (ACCESS MLD ~48 m) and an interior mixing layer with ν ~ 1–2e-3 m² s⁻¹
between the boundary layer and the core (~50–90 m), where Ri sits at 0.3–0.6,
below the 0.7 cutoff.

### Numerics

| | |
|---|---|
| grid | `UniformGrid(160, 400 m)`: 2.5 m cells, 400 m deep; u, T, S at cell centres, fluxes/ν/Ri at faces |
| time step | 10 min, backward Euler (`stepper = :BackwardEuler`) |
| length | 540 d (statistically steady well before; the control's u adjusts on τ_d) |
| advection | centred difference −w(u_{i+1} − u_{i−1})/(2Δz), inside the forcing |
| w at the surface | 0 (prepended in the extractor) |

### Inputs (`extract_column_inputs.py`)

From the last decade (2008–2017) of each ACCESS run, 2°S–2°N band means:

- T, S, u at 140°W on `st_ocean` levels (T, S from `pot_temp`/`salt` or aliases; u on the u grid)
- w from `wt` (on `sw_ocean`) interpolated to T levels, 0 prepended at the surface
- PGF(z): p/ρ₀ = gη + (g/ρ₀)∫(ρ − ρ₀)dz from `pot_rho_0` and `sea_level`, then
  −∂x(p/ρ₀) by a linear fit over 150°W–130°W per level (NaN levels dropped on load)
- τ_x at 140°W, net surface heating, SST

The Julia loader interpolates everything onto the 2.5 m grid (linear, clamped).
Runs required: `ctrl` and `warm`; any others in the file are ignored.

## Experiments

All at control stress.

| run | PGF(z) | T*, S*, SST*, w | isolates |
|---|---|---|---|
| `ctrl` | control | control | baseline; compare with the ACCESS control jet |
| `pgf` | warm | control | pressure-gradient route (Peng) |
| `strat` | control | warm | stratification route (Saenko) |
| `both` | warm | warm | sum; compare with ACCESS shoaling |
| `stratwc` | control | warm T, S, SST; **control w** | check: how much of `strat` is the imposed change in w |

## Diagnostics

Jet metrics (`jet_metrics`), on a 1 m interpolated profile 1–300 m: Umax and
its depth (unreliable on flat tops), eastward-flow centroid depth (primary),
half-max band, surface u, depth of the u = 0 crossing. ACCESS profiles get the
same metrics. Mixed-layer depth from a buoyancy criterion (Δb = 3e-4 m s⁻²)
for both column and ACCESS; KPP's own h is also reported.

Shear layer above the jet (`shear_layer_means`): between the jet maximum and
KPP h, per run, layer means of S² = (∂u/∂z)², N² = g(α∂T/∂z − β∂S/∂z),
Ri = mean N²/mean S², ν. Tests whether the shear rises with the stratification
(ΔS² ≈ ΔN², Ri unchanged, ν maintained) or the layer decouples. The layer mean
includes the N² spike at the core top, so the layer-mean Ri (~1.2) is larger
than the local Ri in the layer (0.3–0.6); quote the local value.

Shear-layer ladder (`ladder`): u_surf = u_core − S̄·L − D, with L = h − z_core,
S̄ the mean shear across that layer, D the velocity drop inside the mixed layer.
Reported per run and for ACCESS as
Δu_surf = Δu_core − Δ(drop across shear layer) − Δ(drop across mixed layer),
with Δu_h (mixed-layer-base velocity) marked. The finer split of the shear-layer
drop into "sharper" (ΔS̄) and "thinner" (ΔL) is argmax-sensitive on a flat-topped
jet and is printed only.

Mixed-layer momentum budget (`ml_budget`): over 0 → KPP h per run,
τ/(ρ₀h) + F_h/h + PGF + adv + Rayleigh = 0, with F_h = −ν∂u/∂z at h (eastward
when the EUC is below); changes vs control printed.

## What the column can and cannot do

- It reproduces the control jet to within the tolerances below and the
  displacement of the core under warming, and it lets the stratification be
  changed with everything else fixed, which no ACCESS diagnostic can.
- It is a frictional jet: with PGF balanced by Rayleigh drag and mixing, the
  core speed responds linearly to a PGF change, whereas the real jet is
  inertial (U ∝ (τg′L)^¼). Amplitude changes are therefore overstated.
- Restoring at 20 d does not hold the ACCESS pycnocline against the column's
  own mixing: the N² peak at the core top is sharper than in ACCESS, so the
  shear layer can hold more velocity drop. Fractional changes in N² and S²
  are not comparable with ACCESS; their ratio is.
- Both effects act on the surface current through the ladder, so the column is
  not used for the surface response; that is diagnosed in ACCESS.

## Running

1. On Gadi, in `extract_column_inputs.py` (or the notebook), provide `DATASETS`
   and `load_vars` (must return `u, wt, pottemp/pot_temp, prac_salt/salt,
   pot_rho_0, sea_level, tau_x, net_sfc_heating`), run it, copy the NetCDF to
   `inputs/`.
2. `julia --project scripts/euc_column_kpp.jl` from the repo root. Needs
   OceanTurb, NCDatasets, PyPlot (`Project.toml`). Edit `INPUT` if the file is
   elsewhere. Settings are at the top of section 2 of the script.

## Checks on each run

- control: core depth within ~20 m and speed within ~30 % of ACCESS; surface u westward and of similar size (if eastward, τ sign is flipped — `tau_x` is eastward-positive)
- control budget panel: −u/τ_d small relative to the PGF in the upper 150 m; Ray/PGF at the centroid printed
- `euc_column_spinup.png`: centroid flat long before day 540
- additivity line: pgf + strat ≈ both (within a few metres)

## Background

Inertial scaling (H ∝ (τ/g′)^½, U ∝ (τg′)^¼) applied to the ACCESS runs: under
warming τ and g′ barely change and so do U and thickness, yet the core shoals.
Shoaling is a displacement, not an inertial adjustment; this repo asks what
displaces it, and what the shear layer above the core does as it rises.

References: Large, McWilliams & Doney (1994); Peng et al. (2022); Saenko et al.
(2011); Pedlosky (1987).
